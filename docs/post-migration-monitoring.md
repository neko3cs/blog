# 切り替え後の監視の記録票

はてなブログから新サイトへ切り替えた（2026-11-23、#5）あとの、検索流入と 404 の記録です。Issue #17 で進めます。

## 1. 期間と終了条件

- 期間: 2026-11-23〜2026-12-21（4週間）
- 終了条件（3つがそろったら終わりにする）
  - 404 が増えていない
  - インデックス登録済みの数が安定している
  - クリック数・表示回数が、切り替え前の水準に戻っている
- 数日の増減は気にしない。数週間たっても下がり続けるとき、特定の記事の順位だけ急に落ちるときは、title・canonical・リダイレクトなどの原因を調べて直す
- 終わったあとは、Search Console が送ってくるメールだけ見る
- はてなブログを非公開にした（#10）直後に、1回だけ追加で見る

## 2. 見るもの

Search Console は「ドメイン」プロパティ `blog.neko3cs.net` を使う。

| 見るもの | 場所 | 見方 |
| --- | --- | --- |
| インデックスの状況 | Search Console →「ページ」 | 「インデックス未登録」の理由に、404・noindex・リダイレクトが増えていないか。登録済みの数が減っていないか |
| 404 | Cloudflare → `neko3cs.net` の Analytics（ステータスコード別。画面の場所は未確認） | 古いはてなのURLが 404 になっていないか。まとまって出ていたら、同じパスを用意するか 301 で逃がす |
| 検索パフォーマンス | Search Console →「検索パフォーマンス」 | 直近7日のクリック数・表示回数・平均掲載順位。切り替え前の同じ長さの期間と比べる |
| 計測 | Google Analytics（`G-55DR4SK29F`）→ リアルタイム | 新サイトのアクセスが計測されているか。1回だけ見ればよい |
